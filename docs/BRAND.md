# ShizukuBot 品牌图标

`public/shizukubot-logo.svg` 是当前网页、favicon 和文档使用的主图标。

设计来源于用户提供的四宫宁月角色设定图，只提取视觉语言：

- 主色 `#9999FF`；
- 浅紫格纹；
- 奶油粉爱心；
- 对称黑色发夹；
- 薰衣草紫蝴蝶结；
- 金色描边、结心与格纹细节。

蝴蝶结采用短结尾，不使用下垂领带造型。图标不使用水滴轮廓，也不使用“雫”字形。它没有复制角色立绘或面部，因此在 32px favicon、QQ 头像和文档页眉中仍能辨认。

使用时保留四周留白，不叠加用户 UID、QQ 号或运行状态。公开页面只能引用仓库内这份静态资源，不从第三方页面热链角色素材。
